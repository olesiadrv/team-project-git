# Conflict Demo

Цей файл створено для демонстрації Git-конфліктів.

## Завдання
1. Кожен студент повинен відкрити цей файл у своїй гілці (або форку).
2. Додайте своє ім’я у список нижче **в кінець файлу**.
3. Якщо виникне конфлікт при злитті — спробуйте його вирішити вручну.
